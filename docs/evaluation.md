# 用真实语境自检

`python -m moqi evaluate examples/evaluation_cases.jsonl` 使用仓库里的 35 条公开示例。它只用于防止已知误判回归，不能证明真实聊天里的准确率。

要判断能否向更广的用户推荐，请在参与者同意后，另建一个**不提交 GitHub** 的 JSONL 文件，每行一个由人标注的例子：

```json
{"id":"case-001","text":"我了个雷炸了","key":"我了个雷","signal":"","expected":"weak"}
```

`expected` 可填 `strong`（可参考已确认含义）、`weak`（只提示相关记录，需要问语境）或 `none`（不应出现）。从真实对话中分别收集“应召回”和“相似但不应套用”的例句；去掉姓名、联系方式等私人信息，最好至少各 50 条。评估命令只读取指定文件，按当前匹配算法逐条给出实际等级和错例，不读取 `MOQI_HOME`，也不联网。

```bash
python -m moqi evaluate 私有例句.jsonl --json
```

逐条检查错例，尤其是**预期 weak/none 却返回 strong** 的情况。还要在真实宿主里记录：每条消息是否真的先调用了 `scan`、用户是否被频繁打断、模型是否把弱匹配当成事实。这些宿主行为不在离线评估范围内。公开示例全通过只满足内部回归条件；真实语境和宿主验证未通过前，发布说明应保持“预览版”。
